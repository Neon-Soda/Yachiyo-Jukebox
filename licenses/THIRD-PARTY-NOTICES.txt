The Windows interface uses the system Microsoft Edge WebView2 runtime.
The installer can download its bootstrapper when the runtime is missing.
Rust and JavaScript dependency versions are recorded in Cargo.lock and the
package-lock.json files. Each dependency retains its own license terms.

User-selected external media tools
----------------------------------
FFmpeg, FFprobe and yt-dlp executables are not included in this installer.
The application opens upstream download pages in the user's browser, then
checks executables selected by the user. It invokes these tools as separate
processes. Their files and licenses remain with the user's download.

FFmpeg and FFprobe: LGPL or GPL depending on the selected build.
Project and licensing: https://ffmpeg.org/legal.html
Windows build provider: https://www.gyan.dev/ffmpeg/builds/

yt-dlp: Unlicense for the project; upstream Windows executables contain
third-party components governed by their respective licenses.
Releases and notices: https://github.com/yt-dlp/yt-dlp

Anyone who separately bundles or redistributes these external tools must
handle the applicable notices and corresponding-source obligations for the
actual binaries they distribute. Selecting tools locally does not change
their licenses. The Yachiyo MIT license does not replace third-party licenses.
