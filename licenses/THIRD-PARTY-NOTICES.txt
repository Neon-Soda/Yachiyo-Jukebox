Yachiyo third-party components

Desktop application
-------------------
Tauri 2: Apache-2.0 OR MIT.
https://github.com/tauri-apps/tauri

Vue 3: MIT.
https://github.com/vuejs/core

The Windows interface uses the system Microsoft Edge WebView2 runtime.
The installer can download its bootstrapper when the runtime is missing.
Rust and JavaScript dependency versions are recorded in Cargo.lock and the
package-lock.json files. Each dependency retains its own license terms.

The tool manifest records the binaries used for this release. Binary tools
are provisioned separately when building from source.

Corresponding source: https://nodejs.org/dist/v24.19.0/node-v24.19.0.tar.xz

third-party components with their own licenses. See yt-dlp-LICENSE.txt and
https://github.com/yt-dlp/yt-dlp/blob/2026.08.19/THIRD_PARTY_LICENSES.txt
Source: https://github.com/yt-dlp/yt-dlp/tree/2026.08.19

FFmpeg 9.0.2 full build from Gyan: GPLv3, see FFmpeg-LICENSE.txt.
