# 隐私政策

**简体中文** · [English](PRIVACY.en.md) · [文档目录](README.md)

最后更新：2026-11-03。适用于本仓库公开版 1.1.0 所描述的功能。

## 适用范围与部署者

Yachiyo Jukebox 是可自行部署的软件。每位部署者使用自己的 Discord 应用、电脑、账号配置和网络服务；项目作者不因提供源码而自动成为所有点歌台的运营者。本说明描述默认项目代码的数据行为，不能代替某个部署者额外配置的日志、代理或服务的隐私说明。

如果你在他人的 Discord 服务器使用点歌台，请向该 Bot 的部署者或服务器管理员询问数据处理方式、访问权限及删除请求。自行对外部署时，应向参与者说明实际运营者、联系方式、代理日志策略及适用的数据处理安排。

## 处理哪些数据

| 数据 | 用途与默认保存位置 |
| --- | --- |
| Discord 应用 / 服务器 ID、网络地址、端口和播放设置 | 建立连接；保存在本机 `user-data/settings.json` |
| 语言、桌面外观、Activity 文案、图片和主题 | 显示和个性化；保存在本机偏好及主题文件中；应用后的 Activity 内容会提供给参与者 |
| Bot Token、Client Secret、主动导入的平台 Cookie、SSH 私钥和主机记录 | 登录或建立隧道；通过当前 Windows 账户的 DPAPI 保存到 `credentials.dpapi`，界面返回是否已配置而非已保存的明文 |
| 工具路径、版本、文件 SHA-256 和检查记录 | 定位并验证媒体工具；保存在 `media-tools.json` |
| Discord 用户 ID / 显示名、服务器 / 频道 / Activity 实例 ID、语音成员关系 | OAuth 身份确认、频道控制授权和共享动态；由 Bot 在运行内存中处理 |
| OAuth 授权码、访问令牌与点歌台会话标识 | 完成 Discord 登录与 API 请求认证；应用代码在会话流程的内存中处理，Activity 不用 localStorage 持久化登录令牌 |
| 歌名、来源链接、时长、封面、播放进度和操作事件 | 搜索、排队、播放和房间同步；房间主要在内存中保存，其他参与者可看到曲目及最近 5 条含显示名的操作动态 |
| 搜索词、媒体请求与来源响应 | 查询歌曲、读取封面和播放音频；按功能发送给相应平台，搜索和封面缓存主要在服务内存中 |
| 音频文件 | 减少重复下载；存放在本机 `user-data/data/audio-cache/` |
| 连接对端地址、请求频率和状态摘要 | 认证请求限流、故障展示和诊断；短期限流状态在内存中，本机状态文件包含连接状态、进程信息及近期事件 |

安装版的 `user-data/` 位于安装目录下；开发模式使用仓库内的独立目录。使用者自行选择的媒体工具仍保存在原位置。

## 哪些网络请求会发生

- **Discord**：Bot 登录、服务器和语音状态、Activity OAuth、身份与频道校验，以及语音音频传输。Activity 授权使用 `identify` 范围；Bot 使用其自身凭据访问所需接口。
- **音乐 / 视频平台及其 CDN**：按你的操作发送搜索词或媒体链接，获取元数据、封面和音频；需要登录时使用你主动配置的对应平台 Cookie。这些服务能够收到连接 IP 及请求信息。
- **你的网络服务**：Activity 网页和 API 经配置的 HTTPS 入口及可选 SSH / 代理传输。VPS、反向代理、DNS 或网络服务商可能依据其配置保留连接与访问记录。
- **主动打开的外部页面**：GitHub、媒体工具上游网站和帮助页面由系统浏览器访问。安装器在缺少 WebView2 时可连接微软下载运行时引导程序。

当前项目代码未加入作者运营的广告、行为遥测、账号注册中心或自动诊断上传服务；没有通过这些服务出售用户数据的功能。正常播放需要第三方网络请求，不能将这一点理解为“完全离线”或“第三方不收集数据”。第三方客户端、运行时和网站适用各自的隐私规则。

## 凭据与临时文件

应用不自动读取浏览器的登录状态。只有主动导入的登录资料用于相应播放流程。桌面凭据使用 Windows 账户绑定的加密，并为个人目录设置访问限制。

Bot、媒体工具或 SSH 运行时仍需使用明文凭据：它们可能出现在受控子进程的内存 / 环境或受限的 `private-runtime/` 文件中。正常停止会清理运行副本；异常断电或崩溃可能留下文件。DPAPI 不代表能防止已控制同一 Windows 账户或管理员权限的程序读取运行中的数据。

主题导出不包含账号凭据，但你填写的文案和上传的图片可能含个人信息。分享前应检查导出内容。

## 保留与清理

- **设置、主题和凭据**：保留到你修改或移除；升级和卸载默认保留 `user-data/`。
- **房间歌单与动态**：随房间结束释放，不作为持久化播放历史保存；停止 Bot 会释放进程内状态。
- **会话**：保存在内存中，离开、过期或服务停止时释放；服务会定期清理过期会话。
- **音频缓存**：默认容量上限 1024 MiB，按最近使用情况淘汰并保护正在使用的文件。结束房间不清空缓存，也没有“24 小时后全部删除”的规则。停止 Bot 后可在应用中清理。
- **诊断、主题导出与备份**：保留在你选择的位置，需自行删除。
- **代理、Discord 和来源平台的记录**：不由本项目统一控制保留期限，应向相应运营者了解。

需要清空本机资料时，先停止 Bot 并从托盘退出应用，再删除对应安装目录的 `user-data/`。单独检查媒体工具所在目录、备份、导出文件和系统浏览器 / WebView2 保存的数据。撤销平台授权、轮换凭据或删除第三方记录，需要在相关服务中操作；本地删除不会替你完成这些操作。

## 诊断与反馈

诊断只在你主动操作后导出到本地，不自动发送给作者。内容包含版本、平台、运行状态、连接模式、缓存摘要和凭据是否配置等标记；默认不导出已保存的凭据全文。诊断仍可能包含路径、时间或错误上下文，分享前应审阅。

[GitHub Issues](https://github.com/Neon-Soda/Yachiyo-Jukebox/issues) 是公开空间。可在此提交不含敏感数据的隐私问题或功能建议；不要上传 Token、Cookie、SSH 私钥、登录文件或完整 `user-data/`。某个部署中的数据访问或删除请求应联系该部署者。

## 变更

本说明随实现更新，并在页首记录日期。自行修改代码、添加日志或接入额外服务的部署者应相应更新其对参与者的说明。
