# Yachiyo 文档

**简体中文** · [English](README.en.md) · [项目首页](../README.md)

Yachiyo 是使用者自行部署的 Discord 音乐 Bot 与 Activity 点歌台。桌面管理端目前面向 Windows 10 / 11 x64。本组文档对应公开版 1.1.0。

## 使用者

| 指南 | 你可以找到 |
| --- | --- |
| [下载与安装](DOWNLOADS.md) | 本项目 Releases、源码、媒体工具、运行时与校验 |
| [配置](CONFIGURATION.md) | Discord 应用、HTTPS、连接方式、登录文件与主题 |
| [点歌台](ACTIVITY.md) | 搜索和链接、合集选择、播放模式、房间生命周期与指令 |
| [常见问题](FAQ.md) | 连不上、无法播放、缓存、后台运行和更新 |
| [工具库](../tools/README.md) | 工具选择、版本与能力检查，以及文件移动后的处理 |

建议第一次按「下载 → 配置 → 点歌台」阅读。仅使用聊天指令时，可以跳过 Activity 的公网 HTTPS 配置。
