# Yachiyo Jukebox documentation

[简体中文](README.md) · **English** · [Project home](../README.en.md)

Yachiyo Jukebox is a self-hosted Discord music bot and Activity jukebox. The desktop manager currently targets Windows 10 / 11 x64. These guides describe public version 1.1.0.

## Users

| Guide | What it covers |
| --- | --- |
| [Downloads and installation](DOWNLOADS.en.md) | Project Releases, source, media tools, runtimes, and checksums |
| [Configuration](CONFIGURATION.en.md) | Discord application, HTTPS, connection modes, login files, and themes |
| [Jukebox](ACTIVITY.en.md) | Search and links, collection choices, playback modes, room lifetime, and commands |
| [FAQ](FAQ.en.md) | Connection and playback problems, caching, background operation, and updates |
| [Tool library](../tools/README.en.md) | Tool selection, version and capability checks, and moved files |

For a first setup, read Downloads → Configuration → Jukebox. Chat-command-only use can skip public HTTPS setup for the Activity.
