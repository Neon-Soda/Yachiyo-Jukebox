# 架构

**简体中文** · [English](ARCHITECTURE.en.md) · [文档目录](README.md)

## 组成

```text
Vue / TypeScript 控制界面
          │ 受限 Tauri commands / 状态事件
          ▼
Rust 桌面管理层 ─── SSH 反向隧道（可选）
          │ 私有命名管道
          ▼
Node Bot / Activity HTTP 服务
          ├── Discord 语音连接
          ├── 搜索、链接与合集解析
          └── yt-dlp / FFmpeg / FFprobe / 音频缓存
```

## 桌面层

Vue 管理表单、主题编辑和状态展示。Rust 管理窗口、托盘、登录自启、文件操作、凭据和后台进程。前端通过明确的本机命令调用功能，不具备通用的 Node 或文件系统访问能力。

后台状态通过事件发送到界面。关闭控制窗口会销毁 WebView2，并将未保存表单暂存于进程内存；重新打开时重建界面。完全退出应用后，未保存草稿不再保留。

主题预览使用按需启动的回环 HTTP 服务，关闭窗口时释放。预览页展示 Activity 内容，不具备桌面本机接口权限。

## 进程与连接

Rust 启动一个 Node Bot，并在选择 SSH 模式时管理一个专用 SSH 进程。Windows Job Object 负责跟踪所属子进程及媒体工具后代进程，管理进程退出时清理它们。

Bot 通过校验进程身份的私有命名管道报告就绪状态与心跳。Bot 异常退出采用退避重试，SSH 断线会重连。连接状态同时参考心跳、实际进程和 HTTP 响应中的应用标识。

## 媒体工具

安装资源只包含 Node.js 运行时，FFmpeg、FFprobe 和 yt-dlp 由用户下载并选择。Rust 校验 Windows x64 格式、正式版本与实际音频能力，原子保存关联；每次启动 Bot 时重新校验，再通过专用环境变量传递具体文件路径。Node 的媒体执行入口使用这些路径，避免取到 PATH 中的另一个同名工具；独立运行 Node Bot 时仍保留 PATH 兼容。

工具检查使用无凭据环境、超时限制和独立临时音频。SHA-256 是文件身份记录，不代表对发布者的认证。工具配置属于个人数据，发行审计禁止媒体工具二进制与个人关联文件进入安装包。

## 音乐与 Activity

Node 后端负责 Discord 登录、语音播放、曲目解析、搜索、房间状态、缓存及 Activity API。Activity 前端位于 `bot/activity/`，与桌面控制界面分别构建。

房间状态按语音频道隔离，但同一 Bot 在同一服务器中同时只服务一个语音频道。音频由 Bot 发送到语音频道；Activity 提供共享控制界面。

## 配置和凭据

普通配置、桌面偏好和主题分开保存。凭据使用当前 Windows 账户的 DPAPI 加密，仅在后端解密；界面获取已配置标记，不读取已保存的凭据内容。

媒体工具与 SSH 需要的运行文件放在受限的 `private-runtime/`，正常停止后删除。导入已有项目、升级加密凭据及其兼容性测试属于当前应用功能。新安装不需要已有配置；这些兼容逻辑只在相应入口或升级条件下运行。

## 构建边界

`scripts/stage.mjs` 从明确的允许列表准备 Bot、Activity、依赖和运行工具。个人目录、环境文件、日志和归档不会进入运行资源。发行审计检查资源范围、模块依赖及安装包校验值。

Windows 路径、IPC、DPAPI 和进程生命周期的具体处理保留在 Rust 层；业务媒体处理继续使用现有 Node 实现。

数据保留与外部请求见 [隐私政策](PRIVACY.md)，构建命令见 [开发指南](DEVELOPMENT.md)。
