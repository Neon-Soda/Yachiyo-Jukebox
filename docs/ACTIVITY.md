# Activity 使用说明

## 进入点歌台

进入服务器的普通语音频道，使用 `/jukebox` 打开 Yachiyo，或通过 Discord 的应用入口打开已启用的 Activity。音频由 Bot 在语音频道播放；只听歌的成员无需打开 Activity。

每个语音频道独立维护房间和歌单。同一个 Bot 在同一服务器内同时只能连接一个语音频道，其他频道不能抢占正在使用的连接。

## 点歌与搜索

可以粘贴单曲链接，也可以按歌名或「歌名 + 歌手」搜索。搜索支持 Bilibili、YouTube 和网易云音乐，结果弹窗显示可用的封面、标题和时长，选择后加入歌单。

所有平台一起搜索时最多显示 12 个结果；选择一个平台时最多 10 个，选择两个平台时各最多 5 个。结果数量会受平台实际返回内容影响。

识别到集合链接时，界面会先询问加入单首还是整个合集：

- Bilibili 多 P：按分 P 顺序加入；显式指定 `?p=` 时使用指定分 P。
- Bilibili 视频合集：按合集成员读取各自的视频链接。
- YouTube 播放列表：可以选择链接中的当前视频或整个列表；纯列表链接使用第一首可用条目作为单首选项。

取消确认不会加入歌曲。音频仍在轮到该曲播放时才准备。网易云整张歌单的批量导入目前不支持。

## 播放与歌单

播放器显示当前曲名、封面、时间和进度，支持暂停/继续、拖动进度、上一首、下一首，以及顺序、循环和随机等播放模式。歌单按钮打开完整列表，选择曲目可以切换播放。

顺序播放完成后会保留歌单。此时添加新歌会从新加入的曲目开始，添加合集则从本次合集的第一首开始；正在播放或暂停时，新曲目排到歌单末尾。

同频道的控制用户共享房间状态。成功操作会显示上移淡出的提示，页面底部保留最近 5 条房间动态，让其他参与者知道谁进行了操作。Activity 激活时，相关反馈集中在点歌台内显示。

## 房间生命周期

- 有成员持续使用 Activity 时，不因播放空闲自动结束房间。
- 最后一位参与者离开 Activity 后，按房间清理流程释放歌单。
- 「结束点歌台」可主动结束房间。
- 语音频道连续 60 秒无人时，结束房间并退出语音频道。
- 仅通过 `/play` 使用 Bot 时，按配置的空闲超时退出。

## 常见问题

**一直显示正在连接**：确认从所在语音频道内打开 Activity，并检查桌面端的 Discord、本地网页和公网状态，以及 Developer Portal 中的 URL Mapping 和 OAuth 配置。

**链接可以在浏览器播放，但 Bot 播放失败**：浏览器的登录状态不会自动提供给 Bot。检查平台登录配置、内容权限、链接有效性和地区限制。

**封面缺失**：来源未提供图片或图片暂时不可用时，会使用默认封面。

**合集读取失败**：源平台可能限制访问或返回不完整数据。可以先选择可用的单首，稍后重新识别；已经加入的歌单不会自动订阅源合集之后的更新。

桌面端的「缓存与诊断」可导出运行状态摘要。提交问题时附上复现步骤、来源链接和界面错误提示即可。
