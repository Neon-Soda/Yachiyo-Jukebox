# 点歌台使用说明

**简体中文** · [English](ACTIVITY.en.md) · [文档目录](README.md)

## 进入房间

进入服务器的普通语音频道，使用 `/jukebox`，或通过 Discord 的应用入口打开已配置的 Yachiyo Jukebox Activity。音频由 Bot 在语音频道播放，只听歌的成员无需打开 Activity。首次点歌时会建立所需语音连接，不必事先手动召唤 Bot。

房间和歌单按语音频道隔离。同一个 Bot 在同一服务器内同时只能服务一个语音频道，其他频道不能抢占正在使用的连接。控制操作会验证使用者是否仍在对应语音频道。

## 搜索与链接

输入歌名或「歌名 + 歌手」搜索，或直接粘贴支持的音乐 / 视频链接。搜索结果弹窗展示可用的封面、标题和时长，选择后加入歌单。

| 选择的平台 | 最多结果数 |
| --- | --- |
| Bilibili、YouTube、网易云音乐全部 | 合计 12 条 |
| 仅一个平台 | 10 条 |
| 两个平台 | 每个平台 5 条 |

实际数量受来源返回内容、网络和权限影响。缺少封面时使用默认图片；搜索到结果不代表账号一定有权播放完整内容。

## 单首还是合集

Activity 识别到集合链接时，先询问加入当前单首还是整个集合。取消不会加入曲目。

| 类型 | 行为 |
| --- | --- |
| Bilibili 多 P | 按分 P 顺序加入；单首选项使用链接指定的 `?p=`，没有指定时使用默认分 P |
| Bilibili 视频合集 | 读取合集成员各自的视频链接，不把整个合集误当成一个视频的分 P |
| YouTube 播放列表 | 可选当前视频或整个列表；纯列表链接以第一首可用条目作为单首选项 |
| 网易云音乐歌单 | 暂不支持批量导入，请使用单曲链接或搜索 |

合集只导入当次识别到的条目，不会自动订阅来源之后新增的内容。数量和完整性受平台访问限制影响。加入的是曲目记录，音频仍在轮到该曲播放时准备。

## 播放控制

播放器显示当前曲名、封面、时长和进度。可暂停 / 继续、拖动进度、切到上一首 / 下一首。歌单按钮打开完整列表，选择其中一项可跳转播放。

| 模式 | 行为 |
| --- | --- |
| 顺序播放 | 依次播放，末尾停止 |
| 列表循环 | 播完末尾后继续循环歌单 |
| 单曲循环 | 当前曲目结束后重复播放 |
| 随机播放 | 随机选择后续曲目 |

顺序播放结束后保留歌单。此时加入新歌会从新加入的曲目开始，加入合集则从本次导入的第一首开始；正在播放或暂停时，新曲目追加到末尾。

## 共享动态

同频道参与者共享播放状态。成功操作会出现缓慢上移并淡出的提示，页面底部保留最近 5 条房间动态，其中包含操作者显示名和操作内容。Activity 激活时，相关反馈主要在点歌台内展示，避免重复聊天消息。

这是共享控制界面，同房间的其他成员也可以点歌、暂停和切歌。操作动态用于帮助协调，并非锁定某一人的独占控制权。

## 房间什么时候结束

- 有成员持续使用 Activity 时，不会因为没有歌曲播放而自动结束。
- 确认最后一位参与者离开 Activity 后，按房间清理流程释放歌单；短暂的网络查询失败不等于所有人离开。
- 点击「结束点歌台」会结束整个共享房间，并尝试通过 Discord SDK 关闭 Activity；若客户端未关闭，可手动退出。
- 语音频道连续 60 秒无人时，结束房间并退出语音频道。
- 仅通过 `/play` 使用 Bot 时，按设置中的空闲超时退出，默认为 5 分钟。

结束房间会清理房间歌单，**不会自动删除磁盘音频缓存**。缓存按容量和最近使用情况管理，可停止 Bot 后手动清理。

## 聊天指令

不使用 Activity 时也能通过指令控制播放；指令应在配置的服务器使用，操作者需在相应语音频道。

| 指令 | 用途 |
| --- | --- |
| `/jukebox` | 打开 Activity；需要启用并配置 Activity |
| `/play link:<链接>` | 加入并播放支持的链接 |
| `/queue` | 查看队列 |
| `/pause` | 暂停 |
| `/resume` | 继续 |
| `/skip` | 跳过当前曲目 |
| `/stop` | 停止播放并结束当前会话 |

合集选择弹窗属于 Activity 界面；聊天指令没有这个弹窗。遇到播放或连接问题，请查看 [常见问题](FAQ.md)。
